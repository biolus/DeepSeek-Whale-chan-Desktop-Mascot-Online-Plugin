# 鲸鱼娘桌宠 · 本地部署大模型 · 联网插件

> 一个完全离线的 Windows 桌宠整合包：本地跑 DeepSeek / Qwen 大模型，桌面上养一只会聊天、
> 会自己冒话、能上网查资料的鲸鱼娘。
>
> **非商业性质**的爱好者整合作品，仅供个人学习、交流与桌面美化使用。请先读
> [`用前须知.txt`](用前须知.txt) 与文末的 [许可与致谢](#许可与致谢)。

---

## 这是什么

| 组成 | 说明 |
| --- | --- |
| **本地大模型** | llama.cpp + GGUF 量化模型，完全离线，断网可用，对话内容不出本机 |
| **鲸鱼娘桌宠** | Live2D 模型 + 独立后端，透明、置顶、点击穿透的桌面外壳（Electron），也有浏览器模式 |
| **联网插件** | 一个本地代理层，让她能检索必应 / 百度再回答，任何 OpenAI 兼容客户端都能接 |
| **显存管家** | 不聊天时不占显卡，说话才拉起模型，安静 60 秒自动卸载 |

控制台是唯一入口，一个 `大肥鱼.bat` 管聊天、桌宠、联网、状态和停止。

## 环境要求

- **Windows 10 / 11**
- **Python 3.10+**，需在 PATH 中（控制台与后端都是 Python）
- **显卡**：8 GB 显存级别即可跑 7B Q4_K_M；无独显可切 `运行时-CPU\`
- 磁盘：模型约 4.4 GB / 个，运行时约 0.3 GB，缓存压缩包约 205 MB

## 快速开始

完整的部署与本机实测记录见 [`大肥鱼本地\说明.txt`](大肥鱼本地/说明.txt)，
桌宠与联网部分分别见 [`鲸鱼娘\说明.txt`](大肥鱼本地/鲸鱼娘/说明.txt)、
[`联网\说明.txt`](大肥鱼本地/联网/说明.txt)。下面是速查版。

### 1. 下载模型权重（必做）

模型不在仓库里，用内置下载器拉取。清单见
[`工具\下载清单.txt`](大肥鱼本地/工具/下载清单.txt)：

```bat
cd /d "<大肥鱼本地>"
python 工具\下载器.py --file 工具\下载清单.txt 8
```

- 多线程分片 + **断点续传**：中断后重跑同一条命令即可接着下
- 自动跳过已下好的文件，下完直接落在 `models\`
- 结尾的 `8` 是线程数，可按带宽调整

**下哪个？** 选一个就够，也可以都下（控制台菜单 `[1]` 会让你选）：

| 模型 | 特点 |
| --- | --- |
| `qwen2.5-7b-instruct-q4_k_m-*.gguf`（分两卷，**两个都要下**） | 纯对话模型，秒回，日常推荐 ★ |
| `DeepSeek-R1-Distill-Qwen-7B-abliterated-Q4_K_M.gguf` | 推理模型，先想再答，每句要等 15~60 秒 |

> 注意：Qwen 那个是两卷分片，`-00001` 和 `-00002` **缺一不可**，只下一个加载会失败。

下载慢或想换源，直接编辑 `工具\下载清单.txt` —— 一行一个任务，格式是
`<下载地址> <保存路径>`，保存路径相对「大肥鱼本地」目录。推荐的国内源：
`hf-mirror.com`（HuggingFace 国内镜像）、`www.modelscope.cn`（魔搭社区）。

### 2. 补齐 Electron 运行时（想用桌面外壳才需要）

`鲸鱼娘\外壳\electron\` 目录未上传。二选一：

- 在该目录执行 `npm install electron@^33` 后把 `node_modules\electron\dist\` 的内容放进 `外壳\electron\`
- 或直接下载 Electron v33 的 Windows x64 压缩包解压到 `外壳\electron\`

不想装 Electron 也可以：双击 `鲸鱼娘\浏览器模式.bat`，功能一样，只是有窗口边框。

### 3. 启动

```bat
大肥鱼本地\大肥鱼.bat
```

控制台菜单：

| 键 | 作用 |
| --- | --- |
| `[1]` | 和模型聊天 —— 选模型、起服务、自动打开网页对话界面 |
| `[2]` | 启动鲸鱼娘桌宠（后端 + 桌面外壳） |
| `[3]` | 命令行对话 |
| `[4]` | 查看状态：当前模型、显存占用、接口地址 |
| `[5]` | 联网插件：让本地模型能上网查资料 |
| `[6]` | 停止所有服务，释放显存 |
| `[0]` | 退出控制台（模型服务继续后台运行） |

> 启动桌宠后，她的大脑并不在线 —— 需要在控制台里手动把模型服务开起来。

## 本地模型

| 项目 | 值 |
| --- | --- |
| 引擎 | llama.cpp b9637（自包含运行时，免安装） |
| 后端 | Vulkan（主力）/ CPU（兜底）/ CUDA（需自备运行库） |
| 默认上下文 | 8192（`control.py` 里的 `CTX`；16384 约占用 5.5 GB 显存） |
| OpenAI 兼容接口 | `http://127.0.0.1:8080/v1`（API Key 随便填，本地不校验） |
| 其他端点 | `/health`、`/v1/models`、`/props`、`/completion` |

任何支持 OpenAI 格式的客户端（Cherry Studio、ChatBox、NextChat、沉浸式翻译等）
都能直接接上，改接口地址即可。

**速度与显存**：Vulkan 版实测约 30~48 token/秒，首字延迟 1 秒左右。已知在
某些第三方 Vulkan 运行时上会掉到 ~2.2 token/秒（GPU 显示 100% 但功耗只有几十瓦，
kernel 效率问题，调参救不了）—— 桌宠按这个速度做了「把话说短、及时放掉显卡」的处理。
详细分析与提速路线见 `说明.txt` 第七、九节。

**关于 CUDA 版**：`运行时-CUDA\` 需要 `cudart64_13.dll` / `cublas64_13.dll` /
`cublasLt64_13.dll`，本包未附带（未安装 CUDA Toolkit）。装好 CUDA 13.x 或补齐这三个
dll 后，把文件覆盖到 `运行时\` 即可尝试。

## 鲸鱼娘桌宠

- **Live2D 形象**：Cubism 4 渲染，含 40+ 表情、动作与物理演算
- **桌面外壳**：Electron 实现的透明、置顶、点击穿透窗口，可拖动、贴边、悬浮球
- **显存策略**：默认 `manage_llm = true` —— 说话才拉起 `llama-server`，说完安静
  `idle_unload` 秒（默认 60）自动卸载，平时显存与 GPU 占用归零
- **主动开口**：`proactive` 开启后，安静 `proactive_gap` 秒（默认 240）她会自己冒话
- **记忆**：`鲸鱼娘\记忆\` 下存人设、对话历史与计价配置；均为本地文件，不上传网络
- **账本 / HUD**：`账本.py` 读真实 token 用量（可接 DeepSeek API 显示余额），
  在 HUD 上显示本轮花费

主要配置在 `鲸鱼娘\记忆\配置.json`，也可以在她界面的「⋯ → 大脑」页签里改：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `model` | — | 当前使用的模型文件名 |
| `manage_llm` | `false` | 是否由她全权管理显存（`true` 说话才拉起、空闲卸载） |
| `idle_unload` | `60` | 空闲多少秒后卸载模型，`0` = 不自动卸载 |
| `proactive` | `true` | 是否主动开口 |
| `proactive_gap` | `240` | 安静多少秒后主动开口 |
| `llm_ctx` | `8192` | 桌宠用的上下文长度 |
| `max_tokens` | `200` | 对话时最多生成多少 token |
| `max_reply_chars` / `max_reply_seconds` | `240` / `35` | 正文长度与生成时长兜底 |

> `对话.json`、`大脑.log`、`日志\` 都是运行后自动生成的本地记录，已被 `.gitignore` 忽略。

## 联网插件

本地模型知识停在训练截止那天，也不会查资料。插件在模型前面加了一层代理：

```
客户端 ──► 8081 代理 ──► 判断要不要联网
                     ├─ 要 ──► 必应/百度检索 ──► 清洗检索式后拼进提问
                     └─ 不 ──► 原样转发
                     ──► 127.0.0.1:8080 模型 ──► 流式吐回客户端
```

把客户端的接口地址从 `8080` 改成 `8081` 即可获得联网能力：

| 用途 | 地址 |
| --- | --- |
| 直连（不联网） | `http://127.0.0.1:8080/v1` |
| 联网版 | `http://127.0.0.1:8081/v1` |
| 调试（直接看搜到了什么） | `http://127.0.0.1:8081/api/search?q=今天北京天气` |

触发联网：句子里出现「搜索 / 查一下 / 最新 / 今天 / 天气 / 多少钱」等词，
或带问号且不超过 60 字；也可以强制用 `@搜索` 开头。

插件的关键在于**检索式清洗** —— 把「DeepSeek-R1 是什么时候发布的？只回答日期。」
压成「DeepSeek-R1 发布时间」再搜，命中率从 1/5 提升到 5/5。细节与验证记录见
[`联网\说明.txt`](大肥鱼本地/联网/说明.txt)。

## 常见问题

**黑窗口中文乱码？**
脚本开头已写 `chcp 936`。若 `说明.txt` / `.bat` 在编辑器里显示为乱码，说明编辑器
按 UTF-8 打开了 GBK 文件 —— 请把编码切到 **GBK / ANSI** 再编辑，存回时也要保持
GBK，否则 `.bat` 里的中文提示会损坏。

**双击 bat 一闪而过？**
说明报错了。在该目录 Shift + 右键 →「在此处打开终端」，手动跑 `python control.py` 看报错。

**端口被占用？**
先跑 `停止AI.bat`，或改 `control.py` 里的 `PORT`。

**显卡没被用上、速度很慢？**
用 `.\运行时\llama-cli.exe --list-devices` 看是否列出你的显卡，没列出就更新显卡驱动。

**想彻底删掉？**
直接删除「大肥鱼本地」整个文件夹即可。本部署不写注册表、不装服务、不改系统设置。

更多问答（显存、复读、按钮点不准等）见
[`大肥鱼本地\说明.txt`](大肥鱼本地/说明.txt) 第九、十节。
